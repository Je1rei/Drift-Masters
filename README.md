# 🏎️ Мастера Дрифта  

**"Мастера Дрифта"** — захватывающая гоночная игра, где главное — искусство дрифта! Почувствуйте себя профессиональным гонщиком, покоряющим крутые виражи и собирающим максимальные очки за идеальные заносы.  

## 📖 Описание  

**"Мастера Дрифта"** — это симулятор, который бросит вызов вашей реакции, мастерству управления и чувству скорости. Берите свою машину, тренируйте навыки дрифта и станьте королём трассы!  

Особенности игры:  
- 🏁 Разнообразные трассы с уникальными углами и сложностями.  
- 🌟 Система очков за подбор предметов.  
- 🎶 Релакс-саундтрек для расслабляющего времяпровождения.  

## 🎮 Как играть  

1. **Выберите автомобиль и уровень** в главном меню.  
2. Используйте управление (клавиатура, сэнсор) для движения и выполнения дрифта.  
   - **W/D** или стрелки — управление.  
3. Выполняйте дрифты, зарабатывайте очки и проходите уровни.  
4. Соревнуйтесь за подобранные монетки!
